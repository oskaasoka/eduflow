# EDUFLOW

Smart Study Management Platform

EduFlow adalah aplikasi manajemen belajar berbasis web yang membantu siswa mengatur tugas, jadwal, dan progres belajar secara terstruktur.

## Features

- Dashboard
- Task Management
- Study Tracker
- Progress Monitoring
- User Authentication

## Tech Stack

- PHP Native
- MySQL
- Bootstrap
- JavaScript

## Installation

1. Clone repository
2. Import database
3. Jalankan di localhost (XAMPP / Laragon)
